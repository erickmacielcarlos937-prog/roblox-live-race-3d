
ROBLOX LIVE RACE 3D

Projeto de corrida interativa em 3D para transmissões ao vivo no TikTok.

Objetivo

Permitir que espectadores participem de corridas usando seus nomes de usuário do Roblox.

Recursos planejados

- Pista de corrida 3D
- Personagens inspirados no Roblox
- Entrada de jogadores pela live
- Cronômetro e classificação
- Linha de largada e chegada
- Identificação do vencedor

Projeto

Desenvolvimento independente e gratuito.
